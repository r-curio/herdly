# Issue tracker

Use GitHub Issues at https://github.com/r-curio/steer. Use gh for reading and publishing issues. External PRs are not a separate request surface. Publish work in dependency order and reference real issue numbers in Blocked by. HITL means a live human interaction or decision is needed; AFK means the scoped implementation can proceed independently once its blockers are closed. Neither label authorizes deployment, changes to real user configuration, or bypassing tool permissions.
